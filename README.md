# Vehicle Service Center Management System

## Project Description

This MySQL mini project simulates a vehicle service center where customers bring their vehicles for servicing.

The database stores:
- Customer details
- Vehicle information
- Mechanic details
- Service records
- Billing information

## Database

Database Name:
`vehicle_service_center`

## Tables

1. Customers
2. Vehicles
3. Mechanics
4. Service_Records
5. Bills

## Practice Queries

The project contains 20 practice queries covering vehicle servicing, mechanics, customer bills, pending payments, service history, revenue, and mechanic ranking.
